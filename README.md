# HW64 - Passport Authentication with MongoDB Atlas

## Description

This project is a Node.js and Express application that implements user authentication with Passport Local Strategy and stores user data in MongoDB Atlas.

### Features

- User registration and login.
- Password hashing with bcryptjs.
- Authentication using Passport Local Strategy.
- Session management with express-session.
- Protected profile page.
- Reading users from MongoDB Atlas.
- Displaying user email addresses and registration dates.
- Passwords are excluded from user list queries.

## Technologies

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Passport.js
- Passport Local Strategy
- express-session
- bcryptjs
- Pug
- dotenv
